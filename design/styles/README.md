# 今晚呢 · 四种风格候选

用户已选择 B 白蓝风格，并进一步要求首页只保留「今晚发起了 → 成功 / 失败」两步。App 已按此简化，当前约束见根目录 `DESIGN.md`；本目录保留四套候选供回看。

每个候选都展示同样的两页和演示数字，便于只比较视觉：

- A 炭黑亮橙：运动计分感，大数字、强对比。
- B 雾白钴蓝：清爽的日常工具，浅色界面、蓝色主操作。
- C 午夜冰银：安静的精密仪表感，深蓝、冰银、细线与并列操作。
- D 沙岩深棕：低饱和器物感，砂色、深棕、方正按钮。

名称暂用「今晚呢」。主功能仅记录成功 / 被拒绝、回看历史、查看两类服务端排行榜；隐私设置放次级入口。数据为风格演示，不是真实用户记录。

生成方式：内置 imagegen。每套一张独立图片，包含记录页和排行榜页。B 的配色已采用，复杂布局已按用户要求移除。

打开 index.html 可总览或放大。用户可选择 A / B / C / D，或指定某套的配色与另一套的布局组合。
